# Reproducibility

Run `python model/research_experiment.py --runs 30 --seed-start 20261019 --output-dir artifacts/paper_reproduction_20261019` from the repository root. The experiment generates separate traffic and session-label files per seed, builds features, performs a stratified session split, fits four comparison methods, and writes per-run metrics, summary statistics, and hashes/version manifests. Labels are generated independently by the simulator and joined by session ID. Seeded IDs and virtual timestamps make generated files byte-reproducible for a fixed seed. The tests `test_feature_builder_joins_independent_ground_truth` and `test_simulator_repeats_exactly_for_same_seed` protect label independence and deterministic generation.

This is still a controlled synthetic study: trials share the same traffic generators and scenario definitions, so 30 seeds measure variation under this simulator rather than generalization to different agents or environments. The stored legacy `results/` metrics must not be cited because labels were previously derived from model features. Wheel and sdist builds succeeded; a clean dependency install and live desktop-agent runs remain unverified. The SDK microbenchmark is separate and is not a deployment performance result.
