# Evaluation protocol

The root README documents the multi-seed harness. It stores simulator ground truth separately from request records and feature tables. Report generation seeds, split strategy, model settings, dependency versions, input/model hashes, confusion-matrix counts, and uncertainty when reproducing results. A label-join test deliberately supplies features that look malicious with a normal ground-truth label; the builder must preserve the supplied label. This blocks the old circular-labeling behavior. Do not describe simulated labels as production incidents or generalize results to unseen MCP deployments.

The harness compares allow-all, explicit rules, Isolation Forest trained on normal training sessions, and supervised logistic regression. Report every comparison, not only the proposed detector. The supervised model uses labels and is a reference comparator, not an unsupervised detector. The explicit-rule baseline uses observable signals aligned with the generated scenarios. Runs vary the generated sessions and split seed but reuse the same scenario families and feature definitions; they are not independent replications on new environments. Confidence intervals are normal approximations over run-level metrics and should be described as such.

The committed reports/figures under `results/` are legacy artifacts with feature-derived labels and are withdrawn from research claims. The deterministic 30-seed run completed with Isolation Forest mean precision 0.552, recall 0.910, F1 0.685, ROC-AUC 0.960, and FPR 0.152. Explicit rules and supervised logistic regression both scored 1.000 on every reported metric in this simulator. This indicates the generated behaviors are separable by hand-designed features and does not establish an advantage for Isolation Forest. See [RESEARCH_RESULTS.md](RESEARCH_RESULTS.md) for intervals and scenario-level recall. Generate outputs to a new directory.

Run `python benchmarks/measure_overhead.py` to measure direct no-op versus guarded SDK invocation latency on the current host. The script prints sample count, Python/platform details, model presence, median/P95 latency and the measured median delta. This synthetic microbenchmark excludes network, subprocess, application logic and production contention; report its output verbatim with the environment metadata.

Observed in this checkout on 2026-10-19: Python 3.12.4, Windows 11 (10.0.26200), 100 measured samples after 10 warmups, shipped Isolation Forest loaded, SQLite and JSONL disabled. Direct no-op median/P95 was 0.0003/0.0003 ms; guarded callable median/P95 was 10.9979/12.3751 ms; measured median delta was 10.9976 ms. This small run is indicative only and should be repeated on the target workload and host.
