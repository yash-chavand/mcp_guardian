# Legacy results — withdrawn from paper use

The reports, plots, dashboards, and `real_agent_attack_report.json` in this directory were produced by earlier prototype runs. The ML evaluation used labels derived from engineered features, so its reported scores are circular and not valid estimates of generalization. The real-agent report has not been independently audited or reproduced in the current validation pass.

Do not cite or use these artifacts as evidence of detection effectiveness. The current deterministic synthetic benchmark and its limitations are documented in [`../docs/RESEARCH_RESULTS.md`](../docs/RESEARCH_RESULTS.md); regenerate it with the command in that document before reporting results.
